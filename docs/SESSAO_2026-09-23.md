## 2. Transferência e cutover seguro

- **Transferência**: stream seguro via SSH
  (`docker save | gzip | ssh contabo gunzip | docker load`), concluído em
  ~72s, sem gravar a imagem em disco intermediário.
- **Divergência de digest explicada**: build local roda em overlay2
  28.5.2, a Contabo usa containerd overlayfs 29.6.1 — os digests de
  metadata diferem, mas `RootFS.Layers` das duas imagens são idênticos
  bit-a-bit, confirmando que é a mesma imagem.
- **Cutover**: `docker compose up -d` (sem `docker compose down`),
  preservando a rede externa `openclaw_default` compartilhada com o
  orquestrador.
- **Resultado**: `openclaw-gateway` e `openclaw-cli` atingiram estado
  `healthy`.
- **Sanity check interno**: Node v24.16.0, Docker CLI 29.8.1, GID 988
  presente no grupo do usuário de execução
  (`uid=1000(node) gid=1000(node) groups=1000(node),988`).
